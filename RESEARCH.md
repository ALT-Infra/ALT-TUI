# Research basis

ALT separates evidence from its working representation. Primary evidence is immutable and addressable; bounded views, indexes, summaries, and learned policies decide what is visible, never what continues to exist. This is a synthesis, not a claim that one paper already demonstrates the complete system under repeated multi-agent compaction.

## Long-horizon context

| Source | Contribution used in ALT | Limit ALT does not inherit |
| --- | --- | --- |
| [Addressable Recall Compaction](https://arxiv.org/abs/2607.25066) (Fujitsu Research, Fujitsu, RIKEN AIP) | Stable addresses and exact recall make removed observations recoverable instead of asking a summary to preserve every future-relevant bit. | Exact storage does not itself solve retrieval, scope, delivery, or repeated-compaction evaluation. |
| [VISTA](https://arxiv.org/abs/2606.30005) (CUHK, Tencent LightSpeed) | Typed addressable blocks, visible context state, exact archive/recover actions, and budget-aware assembly. | Voluntary model management cannot be the only lifecycle mechanism; benchmark adapters are not uniformly lossless. |
| [Delivery, Not Storage](https://arxiv.org/abs/2607.20972) | Context delivery belongs to the harness: important state must reappear without depending on a model remembering to request it. | Cue delivery still requires deterministic authority, provenance, and exact source retention. |
| [ContextWeave](https://arxiv.org/abs/2608.04830) (Fudan, Shanghai Innovation Institute, ByteDance) | Longitudinal executable workflows directly measure whether memory reduces rereading and exploration; richer experience reduced rediscovery and improved workspace outcomes more than compact summaries. | Richer recall also caused more memory-induced failures, and systems differed in retrieval and context budget; exact availability does not guarantee correct selection or use. |
| [Practical Online KV Cache Compaction](https://arxiv.org/abs/2608.00902) (UCSB, LinkedIn) | Online evaluation exposes the future-relevance problem: immediate Attention Matching can damage task accuracy and increase search turns, while delayed queries and simpler token eviction are often more robust. | Search-agent results do not rule out latent cache optimization as a secondary serving layer; delayed compaction can recover or exceed the baseline in some settings. |
| [Slipstream](https://arxiv.org/abs/2605.08580) (Princeton) | Trajectory-grounded evaluation and observable compaction lifecycle are better correctness tests than fluent-summary inspection. | Validation reduces summary failure; it cannot make a summary lossless. |
| [CORVUS](https://arxiv.org/abs/2607.22711) (Purdue, AWS AI Labs) | Synchronize context reduction with the live coding trajectory and distinguish operational state from stale history. | Reduction quality does not remove the need for exact arbitrary recovery. |
| [Learning What Not to Forget](https://arxiv.org/abs/2606.20954) | Learned selection can improve a small visible memory and is a candidate ranking signal. | A learned selector remains distribution-sensitive and must not control deletion of canonical evidence. |
| [Beyond Compaction](https://arxiv.org/abs/2606.11213) | Structured eviction and explicit context lifecycle are preferable to repeatedly rewriting an undifferentiated transcript. | Eviction is safe only when the evicted occurrence remains addressable. |
| [Contextual Memory Virtualisation](https://arxiv.org/abs/2602.22402) | A DAG of state and references motivates separating logical continuity from one physical prompt. | Its current prototype and evidence base are too narrow to serve as ALT's correctness authority. |
| [ACON](https://arxiv.org/abs/2510.00615) (Microsoft) | Optimized or distilled compressors may later improve view quality and cost. | Compression policy optimization still operates below the theoretical ceiling of exact evidence retention. |
| [Eino reduction and summarization middleware](https://github.com/cloudwego/eino/tree/main/adk/middlewares) (CloudWeGo) | Maintained tool-result offload, old-round clearing, summarization hooks, retries, and checkpoint integration execute ALT's intra-agent policy. | ALT supplies durable storage, exact transcript archival, scope enforcement, versioned projections, and lifecycle events around the middleware. |

ALT's three recall operations are a minimal synthesis, not an OpenViking dependency. Queryless `context_browse` is a bounded occurrence catalog analogous to ARC catalog pages, VISTA's context ledger, and CMV's overview surfaces. `context_search` locates evidence when terms are known. `context_open` performs authority-checked, digest-verifiable, bounded byte-range recovery, as required by ARC and VISTA; paging prevents exact recall from becoming a new context overflow. Automatic delivery remains the preferred path for pinned and newly relevant state, with voluntary retrieval as the fallback.

The resulting invariant is:

> Archive exact permitted evidence first; derive a bounded scope-specific view; deliver pinned state automatically; browse when the query is unknown; search when it is known; page exact occurrences when needed; never summarize a summary as the sole surviving source.

ALT tests repeated epochs, paged exact byte recovery, immutable offloads, cursor traversal, cross-scope denial, checkpoint version retention, crash-safe archive ordering, prompt-growth bounds, and addressable compaction chains. ContextWeave sharpens the evaluation target: retrieval must be measured by downstream workspace quality and reduced exploration as well as relevance, while memory-induced failures must remain visible. Stronger empirical claims require long-horizon model evaluations that measure duplicate reads and tool calls, rediscovery tokens and steps, recall under future relevance and distribution shift, leakage, thrashing, task quality, latency, and cost.

## Graph geometry and execution provenance

The graph renderer combines discrete invariants with constrained continuous energy rather than treating a generic force-directed cloud as semantics. [Sugiyama-style layered drawing](https://doi.org/10.1109/TSMC.1981.4308636), [Brandes–Köpf coordinate assignment](https://boriskoepf.de/papers/gd01a.pdf), and [stress majorization](https://www.graphviz.org/documentation/GKN04.pdf) inform hierarchy, ordering, alignment, and relaxation. Exact rectangle separation, port assignment, obstacle routing, crossing metrics, stability, and interaction remain explicit stages.

[Lamport's happened-before relation](https://www.microsoft.com/en-us/research/publication/time-clocks-ordering-events-distributed-system/) prevents storage adjacency from masquerading as causality. [Petri-net theory](https://docenti.ing.unipi.it/~a009435/issw/extra/murata.pdf), [Dapper](https://research.google.com/archive/papers/dapper-2010-1.pdf), [Pip](https://www.usenix.org/conference/nsdi-06/presentation/pip-detecting-unexpected-distributed-systems), and [W3C PROV](https://www.w3.org/TR/prov-primer/) inform concurrent markings, activities, agents, results, responsibility, and return paths. These sources shape projections and diagnostics; ALT's typed event ledger remains the authority.
